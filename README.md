# MiTiendaPOS

## 📌 Descripción
MiTiendaPOS es un sistema de punto de venta diseñado para la gestión de inventarios, ventas y clientes. El proyecto busca ofrecer una solución práctica y sencilla para pequeños negocios, integrando funcionalidades de control de productos, registro de transacciones y generación de reportes.

## 🚀 Características principales
- Gestión de productos (crear, editar, eliminar).
- Control de inventario en tiempo real.
- Registro de ventas y generación de facturas.
- Administración de clientes y proveedores.
- Reportes básicos de ventas e inventario.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** C#  
- **Base de datos:** SQL Server  
- **Frontend:** Windows Forms  
- **Control de versiones:** Git + GitHub
